# 📊 Projeto Acadêmico — Análise Contábil e Planejamento Empresarial

> 🎓 **Projeto de Conclusão de Curso** — Técnico em Contabilidade (Senac)

Desenvolvimento da análise contábil e financeira de uma empresa enquadrada no **Simples Nacional**, utilizando demonstrações contábeis (BP e DRE), análises vertical/horizontal e projeções para apoio ao planejamento empresarial.
